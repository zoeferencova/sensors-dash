# Figures

Diagrams used in the project writeup. Each is an SVG source with a PNG
rendered from it at 2x for print (roughly 152 mm wide at 300 dpi).

| File | Used in |
|------|---------|
| `fig-architecture` | System Architecture — data flow from input through to display |
| `fig-callbacks`    | System Architecture — how one replay tick reaches the screen |
| `fig-lag-window`   | Alert Logic — why the rainfall confirmation window has width |

To regenerate a PNG after editing an SVG, open the SVG in a browser and
export, or render it headless at 2x device scale.
