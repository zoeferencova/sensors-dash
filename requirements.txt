# Direct dependencies only.
#
# Deliberately minimum-version floors rather than exact pins: this was
# developed on Python 3.14, and an exact freeze of that environment
# (numpy==2.5.1, pandas==3.0.5, ...) has no matching wheels on the older
# Pythons most machines run, so pip would try to compile them from source
# and fail. Floors let pip pick versions that fit whatever Python is
# present. Transitive dependencies are resolved by pip and not listed.
#
# Developed and tested against:
#   dash 4.4.1, dash-leaflet 1.1.3, plotly 6.9.0, pandas 3.0.5, Python 3.14.6
#
# dash>=4 matters specifically: the live-update path relies on Dash 4's
# renderer behaviour for dcc.Graph extendData.
dash>=4.0
dash-leaflet>=1.1
plotly>=6.0
pandas>=2.0
